# 课存 · CourseKeep Chrome 扩展

预览版 0.1.0。把课程视频在浏览器内合并并保存为 MP4，不需要复制 cURL，不需要本机服务、Python 或 FFmpeg 安装。

## 安装

1. 从 GitHub Releases 下载 `coursekeep-extension-0.1.0.zip` 并解压。
2. 在 Chrome 打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择含 `manifest.json` 的解压目录。
4. 在工具栏的扩展菜单中点击「课存」，打开下载器。

开发者模式加载用于预览，尚未上架 Chrome Web Store。下载源码 ZIP 的用户应选择 `extension/` 目录，而不是仓库根目录。

## 使用

1. 点击「打开知识星球 / 扫码登录」，在知识星球官方页面登录。
2. 打开有权下载的课程帖子，刷新页面并播放视频。已在安装前加载的视频需要刷新。
3. 回到扩展下载器，点击「刷新已识别的视频」。勾选下载授权确认，再点击「加入下载」。
4. 等待下载、合并和校验，点击「保存 MP4」。批量队列每完成一条会暂停，保存后点击「已保存，继续队列」。

可以一次打开最多 10 个帖子网址；仍需在各页面手动播放来识别。**首版不承诺只粘贴网址即可全自动下载。** 保持原课程页与下载器页面开启；关闭后需要重新识别。账号权限与播放认证由官方页面管理，扩展不会绕过拒绝访问、付费权限或 DRM。

## 状态与限制

- 本版代码和 HLS/安全边界/真实 WebAssembly 合并测试可本机运行，尚需在安装扩展的真实 Chrome 上验证知识星球登录、播放识别、播放认证及完整课程保存。预览版不保证所有课程可下载。
- 仅支持 `videos.zsxq.com` 的完整 MPEG-TS 点播播放列表，无加密或标准单密钥 AES-128；不支持 DRM、直播、多码率主列表、轮换密钥、不连续时间段、分片字节区间或 fMP4。
- 最大 600 MB、1000 分片、3 小时；浏览器需要足够内存。一次处理一个课程，最近一个 MP4 留在内存等待保存。
- 播放 URL 在临时会话存储中保留最多 30 条、30 分钟，浏览器退出清空。无云端服务、无共享登录凭据、无遥测。

## 权限与隐私

`webRequest` 只观察官方页面成功加载的播放列表；`scripting` 用于官方课程页面的播放认证；`storage` 存放临时识别记录。站点权限仅限知识星球网页、视频和认证三个域名。无需 `cookies`、`debugger`、`downloads`、所有网站访问权限或 API 域权限。登录 Cookie 不被扩展读取或存储。

完整声明见 [隐私说明](extension/privacy.html)。本项目不代表知识星球官方产品。公开发布与商店审核不构成内容下载授权，请取得内容权利人的允许。

## 开发和打包

```sh
node --test tests/*.test.js
python scripts/package.py
```

打包使用明确的扩展文件白名单。输出 `dist/coursekeep-extension-0.1.0.zip`，含完整本地 FFmpeg WASM，不从 CDN 加载代码。测试和打包不需要网络。

Manifest V3，最低 Chrome 120。扩展脚本、worker 和 WASM 都随包发布。FFmpeg WASM 第三方许可与源码链接见 [THIRD-PARTY.txt](extension/vendor/THIRD-PARTY.txt)。自有代码采用 MIT，第三方代码遵循其各自许可。
